# NETRAKSH: Final SIH Demo Script (3-5 mins)

## 0:00 - Problem & Introduction
**Speaker**: "Good morning, Judges. We are presenting NETRAKSH, an AI-based Intelligent Video Analytics Platform built specifically for border surveillance. The core problem we solve is transforming existing, passive CCTV feeds into a proactive threat-detection pipeline. Crucially, we designed this to operate in austere environments where continuous cloud connectivity is impossible, and where the integrity of generated alerts must be cryptographically protected."

## 0:30 - Architecture
**Speaker**: "NETRAKSH uses a hybrid Edge-to-Cloud architecture. On the Edge, our pipeline captures RTSP feeds, decodes frames, and runs our AI models locally. By doing this, we reduce our dependence on continuous full-video cloud transmission, forwarding only lightweight event metadata and critical snapshot evidence to the backend."

## 1:00 - Login & Command Center
**Speaker**: *(Show the Login screen)*
"We log into the Command Center. Notice that access is strictly Role-Based. I am logging in as an OPERATOR assigned specifically to Command Area 'East'."

*(Dashboard loads)*
"Because of our strict command-level isolation, I only see cameras, telemetry, and alerts for the East Command. Other sectors are entirely invisible to me, ensuring that operators do not suffer from information overload and that operational security is maintained."

## 1:20 - Live Camera View
**Speaker**: *(Navigate to Camera View)*
"Here you see our local video processing pipeline. The Edge node is currently running a YOLOv8 prototype for localization."

## 1:45 - Detection & Tracking
**Speaker**: "As objects move, they are tracked. We use rule-based behavioral intelligence—such as evaluating geometric line-crossing intersections over the tracked detections—to identify threats automatically without requiring a human to stare at the screen."

## 2:10 - Alert Generation
**Speaker**: *(Trigger a threat/event)*
"A threat just triggered an Event. The Edge packaged the metadata and synced it to the backend. Because this threat matched a high-severity rule, the backend automatically escalated it into an Alert. I now receive a real-time WebSocket notification, safely scoped to my Command."

## 2:35 - Evidence Verification
**Speaker**: *(Navigate to Alerts page)*
"I will now Acknowledge this alert. Under the hood, this uses an atomic state transition in PostgreSQL, guaranteeing exact accountability and preventing race conditions if another operator tries to acknowledge it simultaneously. 
Now, let's look at the Evidence. Every detection generated by the Edge is hashed via SHA-256 and signed via Ed25519 using the Edge's private key. The backend verifies this signature, proving cryptographically that the image and metadata have not been tampered with since they left the camera node."

## 3:00 - Security & Command Isolation
**Speaker**: "To further protect this data, our backend API inherently filters all database queries based on the authenticated JWT token. An operator cannot manipulate the URL or payload to view another command's evidence."

## 3:30 - Offline Story
**Speaker**: "What happens if the border outpost loses internet? NETRAKSH supports store-and-forward operation. The Edge buffers data locally in SQLite during connectivity loss and seamlessly synchronizes it to the backend when connectivity returns, ensuring no critical events are permanently lost."

## 4:00 - Innovation
**Speaker**: "Our primary innovation is merging Edge AI with Zero-Trust Security. We are treating AI threat detections not just as notifications, but as cryptographically verifiable evidence chains, integrated with a prototype permissioned ledger adapter."

## 4:30 - Honest Limitations & Closing
**Speaker**: "Currently, NETRAKSH is an advanced MVP prototype. Our AI uses generic weights and requires formal accuracy evaluation on specialized border datasets, and our ledger is currently a mock adapter. However, NETRAKSH proves that we can unify AI analytics, offline resilience, and cryptographic evidence into a single, secure platform ready for field testing. Thank you."
