# PHASE 6: SFACE ROC / TAR-FAR

## Status
NOT MEASURABLE — NO VALID GROUND TRUTH

## Objective
Evaluate the operational performance curve of SFace across the full spectrum of false acceptance thresholds.

## Metrics Pending
Because no domain-relevant identity ground truth dataset has been approved or integrated, the following metrics are blocked:
- **ROC Curve**
- **EER (Equal Error Rate)**
- **TAR @ FAR = 1e-2**
- **TAR @ FAR = 1e-3**
- **TAR @ FAR = 1e-4**

We strictly adhere to the project constraint: *Do not fabricate accuracy*. No synthetic verification pairs were manufactured, and OpenCV's published LFW accuracy (99.6%) is not substituted for true operational performance on border footage.
