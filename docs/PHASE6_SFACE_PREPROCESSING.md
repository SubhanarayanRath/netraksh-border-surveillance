# PHASE 6: SFACE PREPROCESSING

## Status
VERIFIED

## Implementation Definition
The canonical preprocessing sequence has been strictly verified against the OpenCV `FaceRecognizerSF` reference implementation via brute-force parameter matching in `scripts/bruteforce_preprocessing.py`.

### Target Artifact
`face_recognition_sface_2021dec.onnx`

### Input Contract
- **Shape:** `[1, 3, 112, 112]` (Batch, Channel, Height, Width).
- **Format:** RGB (Natively BGR in OpenCV, transformed to RGB during `blobFromImage` via `swapRB=True`).
- **Data Type:** `float32`.
- **Normalization (Scale):** 1.0 (Pixel values range from 0 to 255. No `/ 255.0` or `128.0` scaling).
- **Mean Subtraction:** None `(0, 0, 0)`.

### Output Contract
- **Shape:** `[1, 128]`
- **Data Type:** `float32`
- **Output Processing:** Must be L2 Normalized for use with Cosine Similarity. The raw vector generated by ONNX has an L2 norm of `~5.26`.

## Code Standard
The integration inside `SFaceEmbeddingModel` enforces this contract:
```python
blob = cv2.dnn.blobFromImage(aligned_face, 1.0, (112, 112), (0, 0, 0), swapRB=True, crop=False)
```
Followed by:
```python
embedding = embedding / np.linalg.norm(embedding)
```
